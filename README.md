# 🧠 Parkinson’s Disease Detection (ML App)

A simple web app that predicts whether a person has Parkinson’s Disease based on voice measurements.

👉 **Live Demo:**
https://parkinsonsdetection-4unl.onrender.com/

---

## 🚀 What this does

* Takes biomedical voice inputs
* Uses a hybrid ML approach to predict Parkinson’s
* Returns a quick result via a clean web interface

---

## ⚙️ Models Used

* Logistic Regression
* KNN
* SVM
* Gaussian Naive Bayes

Predictions are combined using an ensemble approach for better accuracy.

---

## 📊 Dataset

* Voice-based biomedical features
* Includes jitter, shimmer, frequency, etc.
* Output:

  * `1` → Parkinson’s
  * `0` → Healthy

---

## 🛠️ Tech Stack

* Python
* Flask
* Scikit-learn
* Pandas / NumPy
* Tailwind CSS

---

## 💡 Why this matters

Parkinson’s affects movement and speech.
Early detection using non-invasive data (like voice) can actually help in timely treatment.
